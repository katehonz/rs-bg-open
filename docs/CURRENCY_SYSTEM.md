# Валутна Система - Документация

## Основни Принципи

### Важно правило: Дебит и Кредит винаги в основна валута!

В счетоводната система **Дебит** и **Кредит** винаги се записват в **основната валута на фирмата (BGN)**.

Когато операцията е в чуждестранна валута (EUR, USD, GBP и др.), валутната информация се записва по следния начин:

## Полета в системата

| Поле | Описание | Пример |
|------|----------|--------|
| `currencyCode` | Код на валутата | `EUR`, `USD`, `GBP` |
| `quantity` | **Количеството в чуждестранната валута** | `1247.38` |
| `exchangeRate` | Курс към BGN (от БНБ) | `1.9558` |
| `debitAmount` / `creditAmount` | Стойност в BGN = quantity × exchangeRate | `2439.66` |

## Формула

```
Стойност в BGN = Количество в чуждестранна валута × Обменен курс
```

## Примери

### Пример 1: Продажба на услуги в EUR

**Данни:**
- Продажба на услуги за **1247.38 EUR**
- Курс на БНБ: **1 EUR = 1.9558 BGN**

**Как се записва:**

| Сметка | Дебит (BGN) | Кредит (BGN) | Валута | Количество | Курс | Изчисление |
|--------|-------------|--------------|--------|------------|------|------------|
| 411 (Клиенти) | **2439.66** | 0.00 | EUR | 1247.38 | 1.9558 | 1247.38 × 1.9558 = 2439.66 BGN |
| 703 (Приходи) | 0.00 | **2439.66** | BGN | - | 1.00 | - |

**В базата данни:**
```sql
-- Ред 1 (Дебит)
account_id: 411 (Клиенти)
debit_amount: 2439.66          -- В BGN!
credit_amount: 0.00
currency_code: 'EUR'           -- Чуждестранна валута
quantity: 1247.38              -- Сумата в EUR
exchange_rate: 1.9558          -- Курс EUR/BGN
unit_of_measure_code: NULL

-- Ред 2 (Кредит)
account_id: 703 (Приходи)
debit_amount: 0.00
credit_amount: 2439.66         -- В BGN!
currency_code: 'BGN'           -- Основна валута
quantity: NULL
exchange_rate: 1.00
unit_of_measure_code: NULL
```

### Пример 2: Покупка на стоки в USD

**Данни:**
- Покупка на стоки за **500.00 USD**
- Курс на БНБ: **1 USD = 1.7250 BGN**

**Как се записва:**

| Сметка | Дебит (BGN) | Кредит (BGN) | Валута | Количество | Курс | Изчисление |
|--------|-------------|--------------|--------|------------|------|------------|
| 302 (Материали) | **862.50** | 0.00 | USD | 500.00 | 1.7250 | 500.00 × 1.7250 = 862.50 BGN |
| 401 (Доставчици) | 0.00 | **862.50** | USD | 500.00 | 1.7250 | 500.00 × 1.7250 = 862.50 BGN |

## Защо тази система?

1. **Счетоводен стандарт** - Главната книга винаги е в основна валута
2. **Отчети по НСС** - Всички отчети са в BGN
3. **ДДС декларации** - НАП изисква стойности в BGN
4. **Проследимост** - Знаем и оригиналната валутна сума, и курса, и стойността в BGN
5. **Курсови разлики** - Можем да изчисляваме курсови разлики за плащания

## Техническа имплементация

### Frontend (VATEntry.jsx)

При записване се изпращат всички полета:

```javascript
lines: validVATLines.map(line => ({
  accountId: parseInt(line.accountId),
  debitAmount: line.debit > 0 ? line.debit : null,        // Винаги в BGN
  creditAmount: line.credit > 0 ? line.credit : null,     // Винаги в BGN
  currencyCode: line.currencyCode || 'BGN',               // EUR, USD, etc.
  exchangeRate: line.exchangeRate || 1.0,                 // Курс от БНБ
  quantity: line.quantity || null,                        // Сума в чуждестранна валута
  unitOfMeasureCode: line.unitOfMeasure || null,
  description: line.description || vatOperation.description,
  counterpartId: line.counterpartId ? parseInt(line.counterpartId) : null
}))
```

### Backend (entry_line.rs)

```rust
pub struct Model {
    pub id: i32,
    pub journal_entry_id: i32,
    pub account_id: i32,
    pub debit_amount: Decimal,           // Винаги в BGN
    pub credit_amount: Decimal,          // Винаги в BGN
    pub currency_code: Option<String>,   // 'EUR', 'USD', etc.
    pub currency_amount: Option<Decimal>,// DEPRECATED - не се използва
    pub exchange_rate: Option<Decimal>,  // Курс към BGN
    pub quantity: Option<Decimal>,       // Количество в чуждестранна валута
    pub unit_of_measure_code: Option<String>,
    // ...
}
```

## Често срещани грешки

❌ **ГРЕШНО:**
```javascript
// Записване на EUR сумата в debit/credit
debit_amount: 1247.38  // EUR сума
currency_code: 'EUR'
```

✅ **ПРАВИЛНО:**
```javascript
// Записване на BGN сумата в debit/credit
debit_amount: 2439.66     // BGN сума (1247.38 × 1.9558)
currency_code: 'EUR'      // Маркираме че е валутна операция
quantity: 1247.38         // Оригиналната EUR сума
exchange_rate: 1.9558     // Курс от БНБ
```

## Връзка с останалите модули

### Дневници (VAT Journals)
- Дневниците показват данни в BGN
- При нужда се показва и оригиналната валута

### Отчети
- Оборотна ведомост - само в BGN
- Главна книга - BGN + информация за валутата
- ДДС декларации - само в BGN

### Курсове от БНБ
- Автоматично теглене на курсове от БНБ
- Фиксиран курс EUR/BGN = 1.95583 (валутен борд)
- Останалите валути - плаващи курсове
